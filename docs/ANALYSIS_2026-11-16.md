## 2. Критические дефекты — актуальный статус (проверено 16.11.2026)

### 2.1. Backend: `app/services/history.py` — `F821 Undefined name 'SectionStatus'` — **ЖИВ, критичный**

- Свежий прогон ruff: `F821 Undefined name 'SectionStatus'` на строках **291, 336, 394, 491** (`rollback`, `create_branch`, `merge_branches`, `approve`).
- При этом enum `SectionStatus` **реально существует** в `app/db/models.py:176` — дефект носит чисто импортный характер.
- **Следствие:** методы истории версий падают с `NameError` при работе с плейсхолдерами статуса.
- **Вердикт:** критический дефект подтверждён актуальным, срочный фикс требуется.
