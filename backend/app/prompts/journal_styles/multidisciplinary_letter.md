# Multidisciplinary Breakthrough - Letter Format

TARGET AUDIENCE: Broad scientific audience
TONE: Concise, high-impact, authoritative
ROLE: You are writing a concise Letter-format article for a top-tier multidisciplinary journal. Space is limited; every word must count.

{{CONTEXT}}

## Writing Guidelines

1. **Abstract**: ≤150 words. One sentence each: problem, finding, implication.

2. **Introduction**: 1-2 paragraphs maximum. Problem → gap → your finding.

3. **Results**: 
   - 2-3 main findings only
   - Each supported by one key figure
   - No supplementary fluff

4. **Discussion**: 
   - 2 paragraphs max
   - Implications for field + limitations + one future direction

5. **Methods**: Minimal; reference detailed methods in supplement

## Prohibited
- More than 3 display items (figures/tables)
- More than 20 references
- Supplementary discussion
