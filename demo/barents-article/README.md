# barents-article — данные и источники демо-сценария

Материалы для прогона статьи целиком: данные в `data/`, вымышленная литература
в `literature/`, черновик с намеренными дефектами в `draft/`.

**Инструкция — [docs/DEMO_ARTICLE.md](../../docs/DEMO_ARTICLE.md).**
Здесь только сами файлы.

| Файл | Роль в проекте | Категория в сессии |
| --- | --- | --- |
| `data/barents_stations_2026.csv` | **Данные** — 8 станций × 3 горизонта | Данные (`project_data`) |
