## 3. Приёмка по сценарию: чек-лист

Этот чек-лист формируется на основе `PLAN.md`, `interface.md` (ТЗ PaperQA2) и фактического API `paper-qa 2026.8.12`.

### 3.1 Загрузка документов

- [ ] `POST /api/documents/upload` — загрузка PDF/CSV/MD/Office файлов
- [ ] Файлы сохраняются в `data/` (или томе `boasi_data` при Docker)
- [ ] Индексация запускается асинхронно;_progress visible в UI
- [ ] Ошибки индексации попадают в `failed` поле ответа (см. `app/api/documents.py`)
- [ ] Повторный `aadd` того же файла возвращает `None` (дедуп по `dockey`)

### 3.2 Поиск и ответы

- [ ] `POST /api/chat/query` — синхронный ответ с источниками
- [ ] `POST /api/chat/query-async` — фоновый вопрос: возвращает `task_id`, есть endpoints `/api/chat/task/{id}` для опроса статуса
- [ ] `GET /api/chat/quick-query` — быстрый вопрос по глобальной базе
- [ ] RAG Fusion: параллельный поиск по глобальной коллекции + сессионной, merge + rerank
- [ ] Ответ содержит ссылки на источники с форматированными цитатами
- [ ] `answer_max_sources` respects `settings.answer.answer_max_sources`

### 3.3 Генерация статьи по плану разделов

- [ ] Создание проекта: `POST /api/projects/` с именем исследователя
- [ ] Добавление разделов: каждый раздел имеет заголовок и план под-пунктов
- [ ] Генерация раздела: вызывает LLM с контекстом из RAG, возвращает текст раздела
- [ ] Экспорт в Word: `GET /api/export/word?project_id=...` — качает Word-файл с текстом и списком литературы с нумерацией

### 3.4 UI / UX

- [ ] Веб-интерфейс `http://127.0.0.1:5173` — вход через admin-учётную запись
- [ ] Форма загрузки документа с прогресс-баром
- [ ] История сессий: список прошлых запросов с источниками
- [ ] Прогресс SSE для фоновых задач (если включен `verbosity=1`)
- [ ] Обработка ошибок: 429 на логине (`login_max_attempts` в `.env`), сессия архивировалась раньше срока

### 3.5 Инфраструктура

- [ ] `./scripts/start.sh` поднимает backend + React-интерфейс

## 4. Известные риски и ограничения (из PLAN.md §1.1)

- **Dev-модель `qwen2.5:3b`** может давать некачественные русскоязычные ответы; в бой переключается одна величина в `.env`
- **Office-документы** на Windows: `aadd_file(BinaryIO)` падает (`PermissionError`), обёртка сохраняет файл во временный `.tmp` først
- **`chunk_chars=5000`** дефолт плохо сочетается с русскими чанками + Ollama-эмбеддингами; рабочий выбор: `chunk_chars≤1500` для Ollama или `4000/overlap=200` для ST-эмбеддингов
- **Ограничения железа dev-машины:** медленный ответ — норма, не баг; скорость сознательно не оптимизируется
- **Утечка между сессиями:** строгая проверка владельца + физически раздельные каталоги файлов на сессию
