## Волна 1. P1 — корректность (2–3 дня)

### F1. SSE не должен обрываться после первой задачи

**Симптом.** Запущены две долгие задачи. Первая завершилась — вторая
перестаёт обновлять прогресс до F5.

**Причина.** Двойное закрытие:

- клиент: `eventSource.close()` при `!isActiveTask(status)`
  (`dashboard/queries.ts`);
- сервер: `break` после первой `finished` (`backend/app/api/tasks.py:78`).

**Правка.**

1. Убрать `break` из серверного генератора; поток живёт, пока клиент
   подключён, отписка — в `finally`/`CancelledError`.
2. На клиенте не закрывать `EventSource` при завершении задачи; закрытие —
   только в cleanup эффекта.
3. Подписку поднять в один провайдер (пригодится для ящика задач), иначе
   каждый вызов хука создаёт свой поток.
4. Добавить защиту от StrictMode (двойной mount в dev) и переподключение
   после разрыва.

**Приёмка.**

- Две параллельные задачи: после завершения первой вторая продолжает менять
  `progress/step` без F5.
- В сети ровно один `/api/tasks/events` на вкладку.
- После кратковременного разрыва соединение восстанавливается, пропущенные
  статусы подтягиваются из `GET /api/tasks`.
- Завершённые задачи не остаются в `activeTasks` навсегда.
- `pytest tests/test_tasks_sse.py` и `npm test` зелёные.

### F2. Локальное время вместо среза ISO — сделано

**Симптом.** Пользователь в UTC+3 видит время события на 3 часа раньше.

**Причина.** `shortWhen` делает `iso.slice(0, 16)` — это UTC-строка без
конвертации.

**Правка.**

- `Intl.DateTimeFormat('ru-RU', { dateStyle: 'short', timeStyle: 'short' })`
  либо явные `day/month/year/hour/minute`.
- Пустая/битая дата → `''` или `'—'` (как сейчас).
- В `title` — полная дата с зоной, чтобы можно было проверить.

**Приёмка.**

- `2026-10-20T12:00:00Z` в `Europe/Moscow` → `20.10.2026, 15:00`.
- `AdminPage`, `SessionCard`, аудит используют один форматтер.
- Тест с фиксированной `TZ` проходит в CI.

**Что сделано.** Форматирование переехало в `lib/format.ts`:
`shortWhen` (дата с временем), `dayWhen` (только день) и `fullWhen`
(полная дата с зоной — для `title`). Ad-hoc `toLocaleString` /
`toLocaleDateString` из компонентов убраны. Зона зафиксирована в двух местах:
`test.env.TZ` в `vite.config.ts` (Vitest) и `timezoneId` в
`playwright.config.ts` (Playwright — отдельный раннер, `test.env` на него не
действует).
