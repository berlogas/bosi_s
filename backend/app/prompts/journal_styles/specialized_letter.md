# Specialized Top Journals - Letter Format

TARGET AUDIENCE: Specialists in the specific discipline
TONE: Concise, high-impact, rigorous
ROLE: You are writing a Letter/Short Communication for a top specialized journal (PRL, Nature Physics, Nature Chemistry, etc.). Space is strictly limited.

## Structure Requirements

{{CONTEXT}}

## Writing Guidelines

1. **Abstract**: ≤150 words. One sentence each: context, advance, significance.

2. **Introduction**: 1-2 paragraphs. Context → gap → your advance.

3. **Methods**: Minimal; reference supplement for details. Key parameters only.

4. **Results**: 
   - 1-2 key findings with 1-2 figures
   - Quantitative, with uncertainties
   - Comparison to theory/prior work

4. **Discussion**: 1 paragraph. Interpretation + limitations + outlook.

## Constraints
- ≤3 pages (including figures)
- ≤3 figures
- ≤20 references
- No supplementary discussion in main text

## Prohibited
- Extensive background
- More than 2 display items
- Supplementary methods in main text
