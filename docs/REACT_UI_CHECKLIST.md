# Чек-лист регрессии React-интерфейса (Streamlit → React)

Пара к [USER_GUIDE.md](USER_GUIDE.md): каждый сценарий из руководства
исследователя продублирован здесь в виде проверки для нового интерфейса
(`webapp/`). Чек-лист используется на приёмке Фазы 4 плана
[REACT_MIGRATION_PLAN.md](REACT_MIGRATION_PLAN.md) и перед переключением
на React (Фаза 5).

**Как пользоваться.** Запустите оба интерфейса одновременно:

```bash
./scripts/start.sh          # Streamlit + backend
./scripts/start.sh webapp   # React на http://127.0.0.1:5173
```

Пройдите колонку «Проверка» в обоих интерфейсах — результат должен быть
одинаковым (паритет 1-в-1, включая русские тексты ошибок). Автоматические
покрытия указаны в колонке «Тест»: зелёное означает, что сценарий уже
закрыт автоматически и ручная прогонка нужна только для визуала.

## Известные отличия

| Что | Streamlit | React | Решение |
|---|---|---|---|
| Дефолтная вкладка сессии | Документы | Чат (`/s/:id` → `chat`) | осознанно: чат — самая частая операция; зафиксировано при миграции |
| История быстрого чата | `quick-history` в session_state | в памяти компонента | Streamlit-UI эту историю не отображает — паритет сохранён |
