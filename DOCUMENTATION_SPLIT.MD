# Документация: разделение на «для людей» (инструкции) и «разработка» (планы)

Все файлы `.md` проекта, названия — заглавными буквами.
Правило: инструкции для людей = документы для пользователей/администраторов/разработчиков, ведущие за приложение;
планы/репорты разработки = процесс, дизайн, спецификации, разборы — не для руководства перед пользователем.

---

## 1. РУКОВОДСТВА И ИНСТРУКЦИИ ДЛЯ ЛЮДЕЙ (документы)

1. **README.MD** — Обзор платформы, быстрый старт, описание статуса.
2. **USER_GUIDE.MD** — Руководство исследователя (работа в сессии: документы, чат, проекты, заметки).
3. **ADMIN_GUIDE.MD** — Руководство администратора (пользователи, глобальная база, сессии, аудит, бэкап/сброс, регламент).
4. **OPERATIONS.MD** — Руководство эксплуатации (бэкап, восстановление, обновление, диагностика, Docker, режимы).
5. **DEPLOY.MD** — Инструкция по переносу с Windows на Linux-сервер и развёртыванию через Docker.
6. **DOCKER.MD** — Инструкция по Docker-запуску на Windows.
7. **LAUNCH.MD** — Инструкция по запуску (скрипты, порты, типичные ошибки).
8. **DEBUG_CYCLE.MD** — Руководство по отладке цикла работы с Docker.
9. **LEADERS_GUIDE.MD** — Руководство руководителя исследователей (почему платформа нужна).
10. **DEMO_ARTICLE.MD** — Инструкция по демо-сценарию «написать научную статью целиком».
11. **REACT_UI_CHECKLIST.MD** — Чек-лист приёмки интерфейса (QA-документ).
12. **ACCEPTANCE_RUN_2026-11-19.MD** — Инструкция-драйвер приёмки (историческая: пройти полный цикл вручную).
13. **FINAL_ACCEPTANCE_REPORT_2026-11-20.MD** — Отчёт приёмки по сценарию (итог).
14. **SPICE_REPORT.MD** — Отчёт проверки допущений (исторический, фаза 0).
15. **PHASE10_REPORT.MD** — Отчёт по фазе 10 (галлюцинации, правила, эталон).
16. **ANALYSIS_2026-11-16.MD** — Отчёт анализа приложения (новая редакция).
17. **ANALYSIS.MD** — Отчёт анализа приложения (старая редак�ия, существует новая).
18. **ESLINT_VITEST.MD** — Отчёт по ESLint/Vitest (исторический).
