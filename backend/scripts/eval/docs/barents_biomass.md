# Биомасса водорослей в Баренцеве море

Биомасса водорослей измеряется методом GF/F — отношением сухого вещества к сырому.
Средняя биомасса на горизонте 0 м составляет 1,85 мг/м3 в Баренцеве море.

Хлорофилл-а определяют экстракционным методом в ацетоне с последующим измерением
на спектрофотометре. Концентрация хлорофилла-а в среднем 1,495 мг/м3.

Пробы отбирают батернет-граблями на стандартных горизонтах 0 и 10 м.
