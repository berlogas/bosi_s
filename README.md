# boasi_s

Локальная научная RAG-платформа на **PaperQA2** + **Ollama** + **FastAPI** +
**Streamlit**. Работает офлайн, данные не покидают машину.

Исследователь загружает документы (литература, CSV с данными, черновики),
получает ответы со ссылками на источники, готовит статью по плану разделов и
выгружает её в Word.

> Ответ занимает минуты — это следствие CPU-инференса, а не дефект.
> Скорость сознательно не оптимизируется, качество тоже: dev-модель слабая,
> в бою меняется одно значение в `.env`.

## Быстрый старт

```bash
cp .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(48))"   # в SECRET_KEY
./scripts/start.sh                                            # или ./scripts/start.sh docker
```

UI: <http://127.0.0.1> · API: <http://127.0.0.1:8000/api/docs>

Параллельно со Streamlit можно поднять React-интерфейс (миграция,
[docs/REACT_MIGRATION_PLAN.md](docs/REACT_MIGRATION_PLAN.md)):
`./scripts/start.sh webapp` → <http://127.0.0.1:5173> (порт — `WEBAPP_PORT`).

Остановить — `./scripts/start.sh stop`, состояние — `./scripts/start.sh status`.

**Пошаговая инструкция:** [docs/LAUNCH.md](docs/LAUNCH.md).
Развёртывание и бэкапы: [docs/OPERATIONS.md](docs/OPERATIONS.md).

## Что внутри

* **Сессии** со сроком жизни 90 дней, автосохранением состояния и
  «точкой возврата» — после 100 дней тишины архивируются, через 30 дней
  удаляются вместе с файлами.
* **RAG fusion**: пересечение глобальной базы и документов сессии с
  приоритетным ранжированием и разметкой источников 📚 / 📁.
* **Проекты статей**: план разделов, генерация с обязательными ссылками,
  сверка своих данных с литературой, разбор черновика, версии с diff.
* **Экспорт** в Word, Markdown, ZIP с библиографией и исходниками.
* **Фоновые задачи** с прогрессом и настоящей отменой: долгий запрос не
  оставляет «висящий» спиннер.

## Разработка

```bash
cd backend
../.venv/Scripts/python.exe -m pytest -q        # 388 тестов
../.venv/Scripts/python.exe -m ruff check app tests
```

Тесты не ходят в сеть: LLM подменяется заглушкой, эмбеддинги локальные.
